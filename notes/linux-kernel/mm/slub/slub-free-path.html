附 1：与分配路径的对称

  • 快路径：alloc pop ↔ free push c->freelist（同一 cmpxchg 原语）
  • get_freelist 收编 slab->freelist ↔ 远程释放 push slab->freelist
  • cpu partial：入口 = CPU_PARTIAL_FREE（本图）↔ 出口 = CPU_PARTIAL_ALLOC（分配图）

附 2：边角情况

  • 一串释放把满 slab 直接放空：配置 cpu partial 时同样挂到释放者 cpu partial；未配置且 nr_partial ≥ min_partial 时直接还 buddy
